# Teacher's Day Card

A single-teacher interactive Teacher's Day greeting card made with:
- HTML
- CSS
- JavaScript

## Run
Open `index.html` in a browser.

## Replace the teacher photo
Replace:
`assets/teacher-photo.svg`

with your own image, for example:
`assets/teacher-photo.jpg`

Then change the `<img>` source in `index.html` to:
`assets/teacher-photo.jpg`

## Edit the message
Open `index.html` and edit the text inside `.message-panel`.

No framework or installation is required.
